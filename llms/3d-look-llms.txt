# 3DLOOK

> AI-powered body measurement and mobile body-scanning. 3DLOOK extracts 80+ body measurements and 3D body models from two smartphone photos, exposed through two developer products: SAIA Perfect Fit / Mobile Tailor (made-to-measure sizing and size recommendation) and FitXpress (body composition and health/fitness insights).

This llms.txt was generated by the API Evangelist enrichment pipeline from the catalog profile (apis.yml) and the repo artifacts; it is not published by 3DLOOK.

## APIs

- [SAIA Perfect Fit / Mobile Tailor (MTM) API](https://saia.3dlook.me/docs/): REST API to create a person, upload front/side photos, and retrieve 80+ calculated body measurements. Base URL https://saia.3dlook.me/api/v2/. Auth: Authorization: APIKey <key>.
- [FitXpress API](https://docs.fitxpress.3dlook.me/): REST API for body-composition and health metrics (BMI, body fat, BMR), 3D model prediction, and body-progress visualization. Base URL https://backend.fitxpress.3dlook.me/api/1.0/. Auth: Authorization: Token <token>.
